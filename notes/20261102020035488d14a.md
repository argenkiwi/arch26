Crash on device: NoDefinitionFoundException for EditModel$Presenter. Arch26Module had @Module + @ComponentScan but no @Configuration, so @KoinApplication never discovered it and Arch26.onCreate compiled to startKoinWith(emptyList(), ...). This is a silent runtime failure, not a compile error. Fix (verified on a Pixel 4a): add @Configuration to the root module; the bytecode then passes Arch26Module to startKoinWith and the Edit screen works. A root module needs all three: @Module @Configuration @ComponentScan. To diagnose, javap Arch26.class and check the module list passed to startKoinWith.
