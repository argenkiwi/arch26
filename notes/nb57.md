Navigation in this project is handled using Navigation3 and a mutableStateListOf<Route> as the backstack.
- Route: a @Serializable sealed interface.
- MainActivity: hosts the NavDisplay and provides NavEntry for each route.
- Pane functions: take effect lambdas or interfaces to navigate by adding/removing from the backstack.
This provides a simple, type-safe, and highly testable navigation system that doesn't rely on complex navigation controllers.
