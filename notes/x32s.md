---
title: Worker pattern for async work
date: 07/09/2026
tags: []
---

Worker<I, O> is a sealed interface representing an async operation with states: Idle, Busy<I>, and Done<O>.
The rememberWorker(initial, block) helper provides a delegate that:
1. Re-runs the suspend block whenever the state is set to Busy<I>.
2. Updates the state to Done<O> once the block completes.
This pattern replaces traditional 'Loading/Success/Error' state machines in ViewModels with a more declarative Compose-first approach inside Molecule presenters.
