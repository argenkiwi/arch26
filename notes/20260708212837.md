Each feature's logic lives in a @Factory class called Presenter whose operator fun invoke() is @Composable and returns a State data class containing both data and action callbacks. This lets Compose's recomposition engine drive state transitions, replacing ViewModels entirely. Molecule converts the Presenter into a StateFlow via launchMolecule. Example: EditModel.Presenter returns EditModel.State(count, actions: Actions). The pattern is: State data class + nested Actions interface (or a sealed Action sealed interface + a single perform lambda) + @Factory Presenter class.
