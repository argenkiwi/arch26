date: 07/09/2026
tags: []
---

The quakes feature uses a Presenter + Molecule architecture. It fetches earthquake data from GeoNetApi.
- QuakesModel.Presenter: uses rememberWorker to handle fetching and refreshing.
- QuakesView: uses retainMolecule to host the presenter and collect its StateFlow.
- InMemoryQuakesRepository: caches results in a Map of StateFlows, allowing multiple MMI filters to have their own streams if needed, although currently it seems to be used to update the UI via stateFlow(mmi).
